# 🎨 IMPECCABLE AI: Design & Frontend Excellence Framework

Impeccable AI enforces elite-level aesthetic craftsmanship, UI consistency, and fluid micro-interactions across every view.

## Core Directives:
1. **Design System & Palette Consistency**:
   - Strictly adhere to the authentic **Sunlit Sandstone & Obsidian Umber** palette.
   - Light Mode: Canvas `#F0E7DA` / `#E6DACB`, Card `#FAF5ED`, Primary Text `#24160E`, Accents `#BA532B` (Burnt Terracotta) & `#C29244` (Bronze Gold).
   - Dark Mode: Canvas `#120A06`, Card `#20130C`, Primary Text `#FAF5ED`, Accents `#BA532B` & `#C29244`.
   - Never introduce mismatched generic grays (like pure `#000000` or raw `#333333`) where rich umber/warm tones belong.

2. **Typography Hierarchy**:
   - Display/Headers: `Cinzel` serif font (`font-serif`) for monumental presence.
   - Body: `Plus Jakarta Sans` for clean readability.
   - Code & Metrology Telemetry: `JetBrains Mono` (`font-mono`) for precision figures ($L_{\text{cm}}$, $W_{\text{mm}}$, $\%$, coordinates).

3. **Motion & Spatial Dynamics**:
   - Use cubic-bezier easing (`[0.16, 1, 0.3, 1]`) for silky smooth entrances.
   - Maintain 60fps WebGL/Three.js rendering without blocking the UI main thread.
   - Provide non-blocking overlays and instant feedback on all interactive elements.

4. **Zero Visual Clutter**:
   - Use high-contrast hierarchy: Hero metric $\rightarrow$ Contextual badge $\rightarrow$ Supporting telemetry $\rightarrow$ Action CTA.
   - Ensure responsive layout resilience from mobile viewports (375px) to 4K displays (3840px).
